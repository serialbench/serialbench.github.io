# serialbench site

The benchmark console at https://www.serialbench.org/ (serialbench.github.io redirects there).

Astro 7 (Vite 8) with Vue islands and Tailwind 4. Charts are Chart.js 4,
bundled — no CDN. Renders the ruby, python, and c runtime legs of the
benchmark family; the runtime is derived from each data file's name.

## Develop

```
npm install
npm run generate:sample-data   # writes src/data/sample.json (gitignored)
npm run dev                    # http://localhost:4321/
npm test                       # vitest
```

In CI the build clones https://github.com/serialbench/data into `data/`;
the loader (`src/lib/data/loader.ts`) reads `data/runs/**/*.yaml` at build
time. Without a cloned data repo, `src/data/sample.json` (generated by
`scripts/gen-sample-data.mjs`, gitignored) is the fallback payload.

## Data contract

```
combined_results[op][size][format][serializer][envKey] = {
  iterations_per_second, time_per_iteration   # perf ops
  allocated_memory, retained_memory            # op == "memory"
}
environments[envKey] = { ruby_version, os, arch, timestamp, runtime, ... }
libraries = [{ name, format, version, features }]
metadata = { latest_run, total_runs, generated_at }
```

envKey is `{platform}-{runtime}-{version}`, parsed from the data file's
name (`{platform}-ruby-3.4.xml.yaml`, `{platform}-c-gcc.xml.yaml`, …).
Missing entries mean "not measured on that leg" — never zero.
